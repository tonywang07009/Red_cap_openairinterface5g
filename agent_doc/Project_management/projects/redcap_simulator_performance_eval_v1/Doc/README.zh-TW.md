# RedCap Simulator Performance Evaluation 文件

## 用途
- 這個 project 追蹤 paper proxy reproduction 與 simulator performance evaluation。

## 閱讀順序
1. `project_plan.md`
2. `agent_rules.md`
3. 目標 milestone 或 validation matrix
4. 目標 analysis report

## 目前邊界
- 新 paper/demo 指令優先使用 `redcap_interface/mmtc.display.bash`。
- 日常 RFsim setup 指令優先使用 `redcap_interface/mmtc.menu.bash`。
