# D3 Documentation Writer Skill

## Goal
- Create a reusable local Skill so future RedCap feature work updates docs consistently.

## Skill Location
- `redcap_library/redcap_doc_writer_skill/SKILL.md`

## Required Behavior
- Read the active project plan and target `Doc/` page before editing.
- Update English and Traditional Chinese pages together.
- Keep API, Bash, and step-by-step recap sections separate.
- Use concise examples and marker names instead of raw log dumps.
- Mark uncertain 3GPP clause mappings as `[Needs Verification]`.

## Acceptance Criteria
- [x] Skill has valid YAML frontmatter.
- [x] Skill body is concise and self-contained.
- [x] Skill points to project rules instead of duplicating every detail.
