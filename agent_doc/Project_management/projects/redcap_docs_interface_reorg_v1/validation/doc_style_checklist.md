# Documentation Style Checklist

## KISS Rules
- [x] One folder purpose per page.
- [x] Short bullets instead of long paragraphs.
- [x] Link to the next useful file instead of duplicating content.
- [x] Keep raw logs out of stable docs.

## Bilingual Rules
- [x] Add `README.en.md` for American English readers.
- [x] Add `README.zh-TW.md` for Traditional Chinese readers.
- [x] Update both pages when a folder role changes.

## Content Split
- [x] API/config behavior is separate from Bash usage.
- [x] Bash commands are copy-paste friendly.
- [x] Step-by-step recap commands list expected markers when relevant.

## 3GPP Accuracy
- [x] Do not invent clause numbers.
- [x] Use exact local spec references when verified.
- [x] Mark uncertain mappings as `[Needs Verification]`.
