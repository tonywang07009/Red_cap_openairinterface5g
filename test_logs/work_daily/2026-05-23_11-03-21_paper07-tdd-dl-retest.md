## Scope
- Tested TDD downlink throughput using existing RedCap RFsim scenario.
- Deferred FDD planning to a later project-management discussion.

## Results
- TDD DL 106M reverse UDP iperf:
  - receiver `106 Mbit/s`
  - jitter `0.028 ms`
  - loss `284/549831 (0.052%)`
  - active gNB DLSCH `MCS (0) 28`
- TDD DL 141M before PDSCH capability:
  - receiver `141 Mbit/s`
  - jitter `0.033 ms`
  - loss `422/731598 (0.058%)`
  - active gNB DLSCH `MCS (0) 28`
  - verdict: throughput passed, true DL 256QAM not proven
- TDD DL 141M after adding `pdsch_256qam`:
  - receiver `141 Mbit/s`
  - jitter `0.084 ms`
  - loss `422/731299 (0.058%)`
  - active gNB DLSCH `MCS (1) 27`
  - verdict: true DL 256QAM proven
