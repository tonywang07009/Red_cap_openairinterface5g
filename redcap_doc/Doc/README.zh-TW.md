# RedCap 穩定文件

## 用途
- 這裡放穩定的 RedCap 手冊、checklist、spec note、paper note。
- 產生式 log 不放在這裡。

## 文件分區
- API/config 行為：放在 spec note 或 function reference。
- Bash 使用：指向 `redcap_interface/`。
- Step-by-step recap：保留可重現指令與預期 marker。

## 主要路由
- 安裝與重建：`manuals/install/README.zh-TW.md`。
- Paper recovery 教學：`evluation_recover/README.zh-TW.md`。
- 操作介面：從 repository root 讀 `redcap_interface/Doc/README.zh-TW.md`。
- 可重用 evidence：從 repository root 讀 `redcap_library/Doc/README.zh-TW.md`。

## 準確性規則
- 確認過才寫精確 spec clause。
- 不確定的 clause mapping 標成 `[Needs Verification]`。
