# Manual Docs

## Purpose
- Step-by-step RedCap operator manuals live here.
- Manuals should be runnable from the repository root.
- First-time users should start with `redcap_zero_to_build_and_run_guide.en.md`.

## Writing Rule
- Start with prerequisites.
- Then list commands.
- Then list expected markers.
- Keep troubleshooting short and link to project validation files for deeper context.
- For beginner build/run guides, end with one concrete validation target and the exact pass markers.
