# Manual 文件

## 用途
- 這裡放 RedCap 操作流程手冊。
- 手冊內的指令預設從 repo root 執行。
- 第一次使用者先讀 `install/redcap_begin_from_zero.zh-TW.md`。
- 修改後重建先讀 `install/redcap_rebuild_after_changes.zh-TW.md`。
- 新手複現驗證先讀 `install/redcap_newcomer_runtime_gate.zh-TW.md`。

## 撰寫規則
- 先列前置條件。
- 再列指令。
- 再列預期 marker。
- troubleshooting 保持短，深層脈絡連到 project validation。
- 新手 build/run 指南要用一個明確驗證目標收尾，並列出完整通過 markers。
