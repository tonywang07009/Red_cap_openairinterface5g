# RT-M5-032 Case B Runtime Validation Report

## 1. Technical Background
- [RT-M5-032] validates whether the current RedCap/mMTC RFsim path can scale from the stable [30 UE Case B baseline] to [32 UE] without introducing new [RA/Msg2], [Msg4 contention], [PUCCH common fallback], or [gNB restart] failures.
- The run uses the same Case B gNB config, staged UE launch gap, parallel forward ping, disabled reverse ping, and disabled iperf as the 30 UE baseline.
- This keeps the comparison focused on [Random Access] and [contention resolution] behavior rather than throughput load.
